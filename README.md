# Golden Shaark — The Fashion Star

A responsive, static showcase website built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — website structure and content
- `style.css` — design and responsive layout
- `script.js` — mobile navigation and current year
- `images/golden-shaark-logo.jpg` — brand logo

## Preview on your computer
1. Keep all files and the `images` folder together.
2. Double-click `index.html` to open the site in your browser.
3. Internet is needed for the online fashion photos, Google Fonts, and embedded map.

## Publish free
You can publish this folder using GitHub Pages. Do not rename or separate the three main files.
